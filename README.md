# Real-Estate-Price-Trend-Visualization
This project looks at the sales data, for estate to see how prices are changing and growing in different areas over time. The project uses Power BI to make a dashboard with pictures and charts that people can interact with. These pictures and charts help us compare how prices are moving each month how different regions are doing and what kinds of properties are being sold. We can use the real estate sales data to see what is happening with real estate prices and real estate growth patterns in regions.

The analysis includes:

Time-series visualization of average property prices

Heat map to compare monthly prices across regions

Bar chart highlighting regions with the highest price growth

Interactive filters for region, property type, and year

This project shows how to clean up data do calculations with DAX and make interactive dashboards that help people make good decisions when it comes to real estate. The project is about using data to make decisions in the real estate domain. It uses data cleaning and DAX calculations to support this. The interactive dashboard design is also important, for the real estate domain.

Tools Used: Power BI Desktop, DAX, CSV Dataset, PowerPoint, Notepad
